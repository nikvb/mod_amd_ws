# Installer

```bash
curl -fsSL https://raw.githubusercontent.com/nikvb/mod_amd_ws/main/install.sh | bash -s -- -y
```

Run it as root on the FreeSWITCH server. `install.sh` is generated by
`make installer` from `tools/install.sh.in`, with the module sources embedded
as a gzipped tarball whose SHA-256 is checked before use. Do not edit it by
hand.

## What it does

1. **Detects FreeSWITCH** (`fs-detect.sh`). It prefers the running process
   (`/proc/<pid>/exe`) and asks it for `mod_dir` and `conf_dir` over the event
   socket. The event socket address and password come from
   `event_socket.conf.xml`. Without a running switch it falls back to the
   `freeswitch` in `PATH` and the usual layouts (`/usr/lib/freeswitch/mod`,
   `/usr/local/freeswitch/mod`, `/etc/freeswitch`, ...). It reads the version
   from `freeswitch -version` and `libfreeswitch.so` from `ldd`.
2. **Build packages**, only if missing: gcc, make, OpenSSL headers, binutils,
   curl. It uses apt, dnf/yum, zypper or apk, asks first unless `-y`, and never
   adds repositories.
3. **FreeSWITCH headers**, first match wins:
   - `pkg-config freeswitch`, or `include/freeswitch` next to the binary;
   - the distribution's dev package (`libfreeswitch-dev`, `freeswitch-devel`,
     `freeswitch-dev`), but only when FreeSWITCH itself came from that package
     manager, and only at the exact version of the installed FreeSWITCH package
     with no upgrades (an unpinned install could upgrade the core under the
     running switch); if that version is not available, the tarball below;
   - the source tarball of the **exact running version** from GitHub
     (`signalwire/freeswitch/archive/refs/tags/v<version>.tar.gz`). The
     installer extracts `src/include` and `libs/libteletone/src` and writes
     `switch_am_config.h`.
4. **Build and gates.** It compiles against those headers and links the
   running switch's `libfreeswitch.so`. The build must pass `ldd -r` with no
   undefined symbols, export only `mod_amd_ws_module_interface`, and use the
   same `libssl` as the switch. Any failure stops the install before anything
   is changed.
5. **Install.** It backs up an existing module to
   `mod_amd_ws.so.bak.<timestamp>` and moves the new file in atomically.
6. **Configure.** It creates `autoload_configs/amd_ws.conf.xml` only if absent
   (`--host`, `--port`, `--tls` set its endpoint), and adds
   `<load module="mod_amd_ws"/>` to `modules.conf.xml` if absent, keeping a
   backup.
7. **Load** in the running switch: `load mod_amd_ws`, or `reload mod_amd_ws`
   when it is already loaded. If calls are detecting, the reload is refused
   and the installer says so. The new file is already in place, so reload
   later. It never hangs up calls and never restarts FreeSWITCH.

Everything is logged to `/var/log/mod_amd_ws-install.log`, or to
`/tmp/mod_amd_ws-install.log` for dry runs and non-root builds.

## Options

| Option | |
|---|---|
| `-y`, `--yes` | Install build packages without asking. |
| `--dry-run` | Detect and print the plan. Changes nothing, needs no root. |
| `--build-only` | Build `./mod_amd_ws.so` and stop. Needs no root if the build tools are present. |
| `--host H`, `--port P`, `--tls` | Endpoint for a **new** `amd_ws.conf.xml` (default `api.amdy.io:2700`). An existing file is never changed. |
| `--no-config` | Do not create `amd_ws.conf.xml`. |
| `--no-autoload` | Do not edit `modules.conf.xml`. |
| `--no-load` | Do not load or reload in the running switch. |
| `--moddir DIR`, `--confdir DIR` | Override detection. |
| `--fs-src DIR` | Use headers from this FreeSWITCH source tree. |
| `--no-devpkg` | Skip the distribution dev package; go straight to the source tarball. |
| `--uninstall` | Unload (refused while in use), remove the module and the autoload line. `amd_ws.conf.xml` is kept. |

## Tested

| Platform | FreeSWITCH | Header path | Result |
|---|---|---|---|
| Alpine 3.20 (musl), container, switch running | 1.10.11 (apk) | `freeswitch-dev` package | install, reload on reinstall, uninstall |
| Alpine 3.20 (musl), container, switch running | 1.10.11 (apk) | v1.10.11 source tarball (`--no-devpkg`) | install; all 32 call scenarios pass with the installed module; uninstall |
| Ubuntu 22.04 (glibc), not root | 1.10.12 (source, custom prefix) | `<prefix>/include/freeswitch` | `--build-only`, all gates |

## Offline hosts

Copy `install.sh` to the host. It needs no network if the build packages and
FreeSWITCH headers are already there. Otherwise, run it with
`--fs-src /path/to/freeswitch-<version>` pointing at an unpacked source tree.
